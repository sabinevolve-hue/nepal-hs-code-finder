How much customs duty and tax you pay to import bus (Microbus, Van) into Nepal — the rate, the HS code it falls under, and a worked landed-cost example.

Excise duty also applies — not shown here. Vehicles, alcohol and tobacco carry a large excise duty on top of customs duty and 13% VAT, which varies by type, engine size or strength and changes with each budget.
