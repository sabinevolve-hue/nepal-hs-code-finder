Customs duty on Metal cutting shears and similar hand tool in Nepal

Metal cutting shears and similar hand tool is classified under HS code 8203.30.00 (chapter 82, Tools, implements, cutlery, spoons and forks, of base metal; parts thereof of base metal). It attracts 5% customs duty (general), plus 13% VAT on the CIF value and duty.
