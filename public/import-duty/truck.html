Truck import duty in Nepal ट्रक भन्सार

How much customs duty and tax you pay to import truck (Lorry, Pickup) into Nepal — the rate, the HS code it falls under, and a worked landed-cost example.

ट्रक नेपालमा आयात गर्दा साधारण भन्सार दर 30% र त्यसमाथि १३% भ्याट लाग्छ।

Excise duty also applies — not shown here. Vehicles, alcohol and tobacco carry a large excise duty on top of customs duty and 13% VAT, which varies by type, engine size or strength and changes with each budget. The rate below is the customs duty only; for the full landed cost use the official tariff and excise schedule.
