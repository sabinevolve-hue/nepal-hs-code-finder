Customs duty on Knitted or crosheted fabrics, nes width = < 0cm containing rubber thread in Nepal

Knitted or crosheted fabrics, nes width = < 0cm containing rubber thread is classified under HS code 6002.90.00 (chapter 60, Knitted or crocheted fabrics). It attracts 15% customs duty (general), plus 13% VAT on the CIF value and duty.
